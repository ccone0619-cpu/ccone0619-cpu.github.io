# 个人作品集设计规范

## 设计方向

- 风格：Apple-inspired minimalism
- 页面结构：求职型多页作品集，首页求职摘要 + 独立简历页 + 独立作品页 + 首页联系方式
- 关键词：简洁、可信、清晰、留白、系统感、快速扫描
- 内容重心：首页先交代姓名、目标岗位与个人摘要；简历页提供完整经历；作品页先展示个人作品，再用项目流程证明能力
- 职业语义：AIGC 内容创作、AI 漫剧全流程、视觉资产、视频生成、后期剪辑
- 动效：只使用 12px 内的轻位移和淡入，交互时长 150-300ms
- 禁止：渐变装饰、彩色光斑、厚重阴影、过度玻璃化、花哨字体

## 色彩

| 用途 | 色值 | CSS 变量 |
| --- | --- | --- |
| 页面背景 | `#F5F5F7` | `--color-background` |
| 内容表面 | `#FFFFFF` | `--color-surface` |
| 主文字 | `#1D1D1F` | `--color-foreground` |
| 次级文字 | `#6E6E73` | `--color-secondary` |
| 弱化表面 | `#E8E8ED` | `--color-muted` |
| 分隔线 | `#D2D2D7` | `--color-border` |
| 系统蓝 | `#0071E3` | `--color-accent` |
| 浅蓝背景 | `#E8F2FF` | `--color-accent-soft` |
| 状态绿 | `#34C759` | `--color-success` |

蓝色只用于链接、主操作、状态强调和少量标签，不作为大面积主背景。

## 字体

```css
font-family: -apple-system, BlinkMacSystemFont, "SF Pro Display",
  "SF Pro Text", "Helvetica Neue", Arial, sans-serif;
```

- 标题：700
- 正文：400
- 按钮与标签：600
- 字距统一为 `0`
- 正文最小 16px，行高至少 1.45

## 布局

- 内容最大宽度：1240px
- 桌面水平边距：32px
- 手机水平边距：18px
- 区块间距：88-136px，手机端 88px
- 卡片圆角：20-24px
- 图标按钮和触控目标：至少 44x44px
- 作品区使用非对称 12 栏网格，手机端改为单列；项目是能力证明，不是首页主角
- 履历区使用左侧摘要 + 右侧经历列表，不使用内嵌卡片
- 项目内容必须来自真实经历；未提供真实项目名称时，用项目类型或工作流程命名

## 组件

### 导航

- 使用半透明浅灰背景、20px 模糊和 1px 灰色底边
- 桌面显示文字导航，760px 以下切换为菜单按钮
- 首页、简历、作品使用独立 URL，当前页面使用蓝色文字和线条双重标记
- 所有导航项必须可键盘聚焦

### 按钮

- 主按钮使用 `#0071E3`、白色文字和胶囊圆角
- 次操作使用蓝色文字链接
- hover 仅允许轻微位移、颜色和阴影变化
- 交互过渡统一为 240ms

### 卡片

- 白色表面、1px 灰色边框、轻阴影
- 媒体在上，项目信息在下
- hover 最多上移 4px，图片最多放大 1.03 倍
- 不在卡片内部再嵌套装饰卡片

### 弹窗

- 最大宽度 940px，背景为白色
- 遮罩使用约 58% 黑色并配合轻微模糊
- 视频必须使用原生播放控件
- 关闭弹窗时暂停并清理视频

### 互动动效

- 顶部阅读进度使用 `transform: scaleX()`，不动画宽度
- 主视觉仅在精确指针设备上提供 3deg 内的轻微跟随
- 桌面端视频作品卡悬停播放，离开时暂停并复位
- 滚动显现使用 12px 位移和 360ms 淡入
- 减少动效偏好下关闭跟随、悬停播放和位移动画

## 无障碍与响应式

- 正文对比度至少 4.5:1
- 所有可交互元素有可见焦点样式
- 图标使用 Lucide，不使用 emoji 代替功能图标
- 支持 `prefers-reduced-motion`
- 375px、768px、1024px、1440px 下不得出现横向滚动
- 图片提供替代文本，视频提供海报和原生控制
